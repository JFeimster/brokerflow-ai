BrokerFlow ChatGPT plugin

The portable private package connects to BrokerFlow's authenticated MCP endpoint and includes ten workflow skills. It is distributed through the owner-managed private workspace, not the public marketplace.

What the connection can do

Read and write access comes from the authenticated user's current workspace membership and server permissions. Persistent core writes require an explicit user confirmation. Routing is preliminary and read-only. Missing-document copy stops at a draft and internal task with delivery_status: not_sent.

Do not use the plugin to make borrower decisions, retrieve raw documents, send unapproved messages, submit applications or authorize payments.
