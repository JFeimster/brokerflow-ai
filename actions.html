OPERATIONS AND INTEGRATION

BrokerFlow actions

Authenticated MCP tools support organization-scoped broker operations. Existing REST Actions remain available with their established contracts.

BrokerFlow prepares and records operational work. It does not approve, decline, qualify, underwrite, price, submit, guarantee or fund a borrower.

Authenticated MCP capabilities

Intake and routing

capture_borrower_intake records a confirmed, permissioned intake. route_lender_fit computes a read-only preliminary product path from supplied facts.

Human review

request_lender_match_review creates an internal review record. Existing review queue, detail, activity and workflow tools remain available.

Documents and deals

generate_document_checklist returns preliminary guidance. trigger_missing_document_request creates an internal task and draft; delivery remains not_sent. lookup_deal_status reads scoped operational state.

Partner attribution

capture_partner_referral links a confirmed referral to a captured intake and active workspace partner. It does not calculate compensation or authorize payout.

REST Action compatibility

The existing OpenAPI Actions remain a separate integration surface. Their routes, response contracts and forwarding behavior are covered by compatibility tests. Read the Action index and MCP and release documentation for the current inventory.

Private MCP access uses the existing Supabase OAuth flow and current organization memberships. This public page does not expose records or credentials. Shared migration and OAuth activation remain owner controlled.

Operational support only. Lending decisions stay with people.
