# BrokerFlow AI private plugin package

Version 1.2.0 contains the portable Agent Plugins manifest, existing remote Streamable HTTP MCP connection, and ten workflow skills: borrower-intake, lender-fit-routing, review-operations, document-collection, deal-operations, borrower-follow-up, partner-operations, queue-triage, missing-information-prep and broker-automation-architect. The server source registers seventeen tools, retaining all ten prior names and adding the seven core capabilities. It is intended for private owner-approved testing only.

The server requires Supabase OAuth 2.1, an exact approved OAuth client ID allowlist and current per-organization read/write permissions. This source package does not activate or reconfigure OAuth. Prior connection of an older release is not verification of these seven tools. Until the new release is deployed, migrated and tested from the actual private-plugin workspace, its new capabilities are **built but not verified as connected**. Do not treat ZIP creation as installation proof.

Persistent intake, deal, document-request and referral workflows require owner-authorized application of `20261019165744_brokerflow_core_workflows.sql` after the existing review/rate-limit/task migrations. They reuse canonical leads, referrals and events. The four new write tools require `confirmed: true` after explicit user confirmation and stable retry keys. The read-only routing and checklist tools return preliminary guidance, and `lookup_deal_status` reports operational state separately from review status.

The synthetic workflow is capture intake → preliminary routing → confirmed human review → checklist → confirmed missing-document draft/task → deal status → confirmed partner referral. Missing-document delivery remains `not_sent`; there is no borrower messaging or lender-submission integration. See `../docs/MCP_CORE_TOOL_EXAMPLES.md`, `../docs/MCP_OAUTH_SETUP.md` and `../docs/MCP_RELEASE_CHECKLIST.md`. Run `npm run package:plugin` at the repository root to produce the private ZIP. Keep the existing endpoint and plugin identity; do not publish this package publicly.
